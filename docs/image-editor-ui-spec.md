# 새 이미지 편집기 UI 명세

작성일: 2026-11-17  
관련: [설계 계약](image-editor-design-contracts.md), [세 비율 와이어프레임](image-editor-wireframes.svg)

## 1. 화면 구성

```text
프로젝트로 | 작업명 | 파일·편집·이미지·레이어·선택·보정·보기 | 저장 | 내보내기
선택한 도구 이름 | 해당 도구 옵션 | 변형 적용·취소
문서 탭: 캐릭터 A • | 배경 B | AI 요청 당시 작업
┌────────┬────────────────────────────┬───────────────────┐
│도구 그룹│                            │ 속성 / AI 편집     │
│이동·선택│         편집 이미지        │                   │
│페인트  │  가로 / 정사각 / 세로      ├─ 높이 조절 ────────┤
│리터칭  │                            │ 레이어 / 기록      │
│표현·보기│  선택 경계·핸들·커서       │ 혼합·불투명도      │
│전경색  │                            │ 트리·썸네일·마스크 │
└────────┴────────────────────────────┴───────────────────┘
맞춤·100% | 줌·규격·수정 여부 | 현재 편집 대상 | 비교 | 저장 상태
```

툴바와 속성 패널은 이미지 비율에 따라 위치가 바뀌지 않는다. 문서를 화면에 맞춰 중앙 표시하고 viewport로 이동한다. 오른쪽 패널은 너비 250~400px, 속성/레이어 사이 높이를 조절하고 접을 수 있다. 배치는 로컬에 저장한다. 가로·정사각·세로 이미지는 동일한 화면에서 각 프리셋 비율대로 표시한다.

740px 이하에서는 오른쪽 패널을 하단 시트로 연다. 도구는 왼쪽, 주요 파일 명령은 상단과 명령 검색에 유지한다. 두 손가락 핀치·중심 이동, 손가락 한 개는 화면 이동, 펜은 편집 도구·필압으로 처리한다. 실제 태블릿 입력 검증은 배포 후 수행한다.

## 2. 시작·열기·이탈

빈 화면에서 프로젝트 이미지, 로컬 파일, 최근 저장 작업을 연다. 세 프리셋 카드로 빈 작업을 만들 수 있다. 파일 드롭·클립보드 이미지는 실측 규격을 검증한다. 지원 밖 이미지는 오류를 표시한다. 기존 작업은 탭에 유지하고 새 작업을 추가한다. 최대 8개까지 열 수 있다.

최근 작업에는 썸네일·작업명·갱신 시간이 보인다. 복구본은 서버 저장과 구분하고, 이전 저장 버전은 최신 작업을 먼저 저장한 뒤 열 수 있다. 저장 충돌 시 다시 열기·작업 복제·재시도 경로를 이용한다. 생성 중인 문서는 수신 중단 후 닫는다. 수정 중 브라우저 이탈에는 기본 미저장 확인을 사용한다.

## 3. 도구와 속성

| 그룹 | 도구와 주요 옵션 |
| --- | --- |
| 이동·구도 | 이동, 변형, 원근/기울이기 속성, 3×3 워프, 크롭, 프리셋·90° 회전, 정렬·스냅 |
| 선택 | 사각·타원·올가미·다각형·색상, 교체/추가/빼기/교차, 허용치·인접·합성 샘플, 이동·반전·페더·확장/축소 |
| 페인트 | 크기·경도·불투명도·흐름·간격·선 보정·필압, 지우개, 전경/배경, 스포이트, 채우기·선형/방사형 그라데이션 |
| 리터칭 | Alt 기준점 복제 도장·색상 힐링, 영역 패치, 닷지/번·스머지·블러/샤픈·국소 밀기 |
| 표현 | 텍스트, 사각·타원·직선·화살표·다각형, 펜/베지어 패스 |
| 보기 | 손·확대/축소·맞춤·100%, 원본/분할 비교, 격자·중앙 가이드·내비게이터 |

도구 옵션 줄은 현재 도구에 필요한 값만 보여준다. 속성 패널은 선택 레이어 종류에 맞춰 배치·텍스트·도형·패스·마스크·효과·스타일을 제공한다. 잠금 상태에서는 내용 편집을 막는다. 알파 잠금은 기존 페인트 alpha 안으로 칠하기를 제한한다.

레이어 목록에서 Ctrl/Cmd·Shift로 다중 선택한다. 그룹은 접고 펼칠 수 있다. 드래그는 순서 변경, 그룹에 Shift 드롭하면 그룹 안으로 이동한다. 내용 썸네일과 마스크 대상을 구분하고 하단 상태에도 현재 대상을 표시한다. 그룹·복제·병합·평면화·클리핑·선택→마스크를 공통 명령으로 제공한다.

커브는 그래프에서 점을 추가·이동·삭제한다. 패스는 화면에서 앵커·제어점을 끌어 조절하고 속성에서도 수치를 입력한다. JSON 편집은 사용자 흐름에 노출하지 않는다. 경계 다듬기는 확장/축소·페더·경계 색 보정으로 마스크를 재편집한다. 모델 피사체 선택은 처리 진행·중단·선택 적용 단계를 구분한다.

## 4. AI 편집 상태

선택 영역 없음 → 안내. 설정 → 모델·입력 원본/합성·프롬프트·제외·강도·Steps·Scale·Seed·후보 요청 수·Anlas 추정. 실행 → 진행 상태·결과 수신 중단. 완료 → 후보 썸네일·비교·레이어 추가·요청 당시 작업 열기·삭제.

비교는 현재 결과 위에 요청 마스크로 제한한 후보를 보여주며 실제 레이어를 추가하지 않는다. 레이어 추가 후에는 일반 마스크·효과·순서로 수정할 수 있다. 실패해도 설정과 기존 후보는 남긴다. 반복 생성 도중 비용 상한이 달라지면 다음 요청을 중단한다.

## 5. 저장·출력 상태

상태 줄은 로컬 복구 저장 중 / 로컬 복구됨·서버 저장 중 / 서버 저장됨 / 새 변경 대기 / 서버 저장 실패·로컬 유지 / 충돌을 구분한다. 미확정 변형은 도구 옵션에 적용·취소와 Enter/Esc를 표시한다. 작업명 옆 점과 문서 정보는 서버 응답 시점이 아닌 내용 상태로 갱신한다.

내보내기 화면은 형식·품질·JPEG 배경·파일명·다운로드/프로젝트·폴더·열린 작업 일괄 출력을 제공한다. 현재 프리셋 크기로 합성한다. 프로젝트 이름 충돌은 대상 백업 후 덮어쓰기 화면을 띄우고, 출력만 성공한 경우 연결 정보 복구 화면을 제공한다.

## 6. 단축키·접근성

V 이동, B 브러시, E 지우개, M 사각 선택, L 올가미, T 문자, I 스포이트, H 손, P 펜. Space 화면 이동, Enter 변형/패스 확정, Esc 취소, [ / ] 브러시 크기. Ctrl/Cmd+S 저장, Z/Shift+Z/Y 이력, C/X/V 복사/잘라내기/붙여넣기, A 전체 선택, D 해제, J 복제.

입력·선택 상자·dialog·contenteditable·IME 중에는 편집 단축키를 가로채지 않는다. 숨겨진 화면은 문서 단축키를 처리하지 않는다. 도구와 주요 컨트롤에 접근성 이름·focus-visible·상태 live region을 제공한다. 색만으로 저장 성공·실패를 구분하지 않는다.
