# 이미지 편집기 사용자 안내서

작성일: 2026-11-17. 새 수동 편집기 기준. 화면의 도움말에서도 주요 내용을 확인할 수 있습니다.

## 시작하기

1. 새 작업을 누릅니다.
2. 프로젝트 이미지에서 선택하거나 내 기기 이미지를 선택합니다. 빈 캔버스로 시작할 수도 있습니다.
3. 도구를 고르고 편집합니다. 이미지를 더 겹치려면 바로 보이는 이미지 불러오기를 누릅니다.
4. 레이어·마스크를 다시 편집하려면 작업 저장을 누르고 이름을 입력합니다.
5. 완성 이미지는 이미지 내보내기에서 PNG·JPEG·WebP로 만듭니다.

지원 캔버스는 가로형 1216×832, 정사각형 1024×1024, 세로형 832×1216입니다. PC에서 숨겨진 명령을 찾거나 모바일에서 전체 메뉴를 보려면 모든 명령을 누릅니다.

## 작업 저장과 이미지 내보내기

| 동작 | 용도 |
| --- | --- |
| 새 작업 | 이미지 또는 빈 캔버스로 새로운 편집 시작 |
| 작업 불러오기 | 레이어를 보존한 정식 작업 또는 임시 편집 이어하기 |
| 작업 저장 | 현재 작업의 최신 레이어·마스크·보정을 저장 |
| 다른 이름으로 저장 | 기존 정식 작업을 남기고 다른 이름의 새 작업으로 저장 |
| 이미지 내보내기 | 합성 결과를 PNG/JPEG/WebP로 다운로드하거나 프로젝트 이미지 폴더에 넣기 |
| 작업 탭 × | 화면에서 작업 닫기. 변경이 있으면 저장/버리기/취소 선택 |
| 불러오기 목록의 삭제 | 선택한 작업과 전용 자산 삭제. 원본·이미 내보낸 이미지는 유지 |

정식 저장 위치는 R2의 현재 프로젝트 / 편집 작업입니다. 프로젝트 이미지 폴더의 일반 이미지와 분리됩니다. 이미지 파일만 내보내면 레이어 구조는 포함되지 않습니다.

자동 저장은 별도의 임시 공간에 최신 편집을 보관합니다. 연속 편집은 5초 동안 모아서 저장하며, 단순한 화면 이동·도구 변경은 저장하지 않습니다. 프로젝트당 최대 10개·256MiB, 마지막 저장 후 7일까지 이어할 수 있습니다. 제한 안내가 나오면 작업 저장 후 필요 없는 임시 편집을 삭제하세요. 네트워크 장애·브라우저 강제 종료 때 마지막 변경까지 저장된다고 보장하지 않으므로 작업 저장을 사용하세요.

동시에 여러 창에서 같은 작업을 저장해 충돌하면 현재 편집을 다른 이름으로 저장하거나 목록에서 최신 작업을 다시 불러오세요. 정식 작업을 삭제한 다른 창의 오래된 편집은 원래 ID로 재저장되지 않습니다.

## 모바일과 펜

- 한 손가락 또는 펜은 현재 선택한 도구를 실행합니다. 브러시를 골랐다면 칠하고, 선택 도구를 골랐다면 영역을 선택합니다.
- 화면만 이동하려면 손 도구를 선택하거나 두 손가락으로 움직입니다. 두 손가락을 벌리거나 모으면 확대·축소됩니다.
- 두 손가락 제스처로 바꾸면 진행 중이던 미확정 획은 취소됩니다.
- 이동 도구는 레이어 위치를 바꾸는 도구입니다. 화면 이동용 손 도구와 구분하세요.
- 색상을 누르면 하단에서 색조·채도·명도, HEX/RGB, 기본색과 최근 색을 선택하고 적용할 수 있습니다.
- 복제 도장·힐링은 샘플 위치 선택을 누르고 복사할 곳을 한 번 선택한 다음 고칠 곳을 문지릅니다.
- 변형은 적용/취소, 펜·다각 선택은 선택·패스 완료 버튼으로 확정합니다.

## 도구별 사용 방법

| 도구 | 사용 방법 |
| --- | --- |
| 이동 | 선택한 레이어를 끌어 위치를 바꿉니다. 화면 이동은 손 도구를 사용하세요. |
| 변형 | 모서리 핸들로 크기, 위쪽 핸들로 회전을 조절하고 적용을 누릅니다. |
| 워프 | 9개 제어점을 끌어 형태를 바꾸고 변형 적용으로 확정합니다. |
| 사각 선택 | 사각 영역을 선택합니다. 선택한 동안 브러시는 그 영역 안에서만 칠해집니다. |
| 타원 선택 | 타원 영역을 선택합니다. 선택 옵션으로 더하기·빼기·교차를 고릅니다. |
| 올가미 | 손가락·펜·마우스로 둘러 그려 자유로운 모양을 선택합니다. |
| 다각 선택 | 여러 점을 찍고 더블클릭 또는 선택 완료로 닫습니다. |
| 색상 선택 | 비슷한 색을 선택합니다. 허용치와 인접 옵션으로 범위를 조절합니다. |
| 선택 이동 | 선택 경계만 움직입니다. 이미지 자체는 이동하지 않습니다. |
| 자르기 | 영역을 끈 뒤 가로형·정사각형·세로형 중 출력 구도를 선택합니다. |
| 브러시 | 전경색으로 칠합니다. 이미지 위에서 시작하면 새 페인트 레이어를 만듭니다. |
| 지우개 | 페인트를 지우거나 이미지의 마스크를 편집해 일부를 숨깁니다. |
| 채우기 | 연결된 비슷한 색 영역을 전경색으로 채웁니다. 허용치를 조절할 수 있습니다. |
| 그라데이션 | 시작점에서 끝점까지 끌어 전경색과 배경색 사이를 채웁니다. |
| 스포이트 | 현재 합성 이미지의 색을 전경색으로 선택합니다. |
| 복제 도장 | 샘플 위치 선택 후 복사할 곳을 누르고, 고칠 곳을 문지릅니다. PC는 Alt+클릭도 가능합니다. |
| 색상 힐링 | 선택한 샘플을 경계의 색에 맞춰 복사합니다. 샘플 위치를 먼저 지정하세요. |
| 영역 패치 | 수정할 영역을 먼저 선택하고 복사할 위치 쪽으로 끕니다. |
| 닷지 | 문지른 부분을 밝게 합니다. 새 보정용 페인트 레이어에 반영합니다. |
| 번 | 문지른 부분을 어둡게 합니다. 불투명도로 강도를 조절합니다. |
| 스머지 | 문지르는 방향으로 색을 밀어 경계를 섞습니다. |
| 블러 브러시 | 문지른 부분의 세부를 부드럽게 합니다. |
| 샤픈 브러시 | 문지른 부분의 윤곽을 강조합니다. |
| 국소 밀기 | 브러시 반경 안의 형태를 끄는 방향으로 조금씩 밀어냅니다. |
| 문자 | 위치를 누르고 내용을 입력합니다. 속성에서 글꼴·크기·색·행간을 수정합니다. |
| 사각형 | 끌어서 사각형을 만듭니다. 선 색·채우기·선 굵기를 지정하세요. |
| 타원 | 끌어서 타원을 만듭니다. 채우기 없음으로 윤곽만 만들 수 있습니다. |
| 직선 | 시작점에서 끝점까지 끌어 직선을 만듭니다. |
| 화살표 | 끄는 방향으로 화살표를 만듭니다. |
| 다각형 | 다각형을 만들고 속성의 변 수로 모양을 조절합니다. |
| 펜·패스 | 점을 찍고 끌어 곡선 핸들을 만듭니다. 완료 후 앵커·핸들을 재편집합니다. |
| 손 | 이미지 내용에 영향을 주지 않고 화면을 이동합니다. 두 손가락 이동도 가능합니다. |
| 확대·축소 | 누르면 확대합니다. PC에서는 Alt와 함께 눌러 축소합니다. |

## 레이어·마스크·보정

이미지 위에서 브러시를 시작하면 페인트 레이어를 만들어 원본을 보존합니다. 원본은 기본적으로 잠겨 있습니다. 직접 변형해야 한다면 레이어를 복제하거나 잠금 상태를 확인하세요.

마스크는 지우는 대신 보이는 범위를 정합니다. 레이어의 이미지와 마스크 썸네일 중 무엇을 선택했는지 하단의 대상을 확인하세요. 선택 영역이 남아 있으면 브러시가 그 안에서만 작동하므로, 원하는 곳에 그려지지 않을 때 선택 해제를 확인하세요. 불투명도·흐름이 0이면 그려지지 않습니다.

보정 메뉴는 재편집 가능한 조정 레이어를 만듭니다. 밝기/대비·노출·색조/채도·색상 균형·흑백·레벨·커브·그라데이션 맵을 사용할 수 있습니다. 블러·샤픈·모자이크도 제공합니다. 속성에서 레이어 스타일·혼합·효과 순서와 강도를 조절합니다.

피사체 선택은 최초 모델 다운로드 후 기기에서 처리합니다. 결과는 선택 영역으로 만들고 마스크로 보완할 수 있습니다. 정밀한 경계는 마스크 브러시와 경계 다듬기를 함께 사용하세요. AI 인페인트는 이미지 생성 탭에서 수행합니다.

## PC 단축키

Mac은 Ctrl 대신 Cmd를 사용합니다. 브라우저가 예약한 일부 키와 클립보드 기능은 브라우저·권한 설정의 영향을 받을 수 있습니다.

| 키 | 동작 |
| --- | --- |
| Ctrl/Cmd+S | 작업 저장 |
| Ctrl/Cmd+Shift+S | 다른 이름으로 저장 |
| Ctrl/Cmd+O | 작업 불러오기 |
| Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl/Cmd+C / X / V | 이미지 복사 / 잘라내기 / 붙여넣기 |
| Ctrl/Cmd+Shift+C | 합성 내용 복사 |
| Ctrl/Cmd+A / D / J | 전체 선택 / 선택 해제 / 레이어 복제 |
| V / B / E / M / L / T / I / H / P | 이동 / 브러시 / 지우개 / 사각 선택 / 올가미 / 문자 / 스포이트 / 손 / 펜 |
| Space 누르는 동안 | 임시 손 도구 |
| [ / ] | 브러시 크기 감소 / 증가 |
| Enter / Esc | 변형·패스 확정 / 취소·메뉴 닫기 |
| Delete | 선택 레이어 삭제 |
| ? | 도움말 |

입력창에서 Ctrl/Cmd+C/X/V는 텍스트에 적용됩니다. 이미지 복사는 가능한 경우 실제 시스템 클립보드에 PNG를 기록합니다. 권한이 없으면 편집기 내부에 복사했다는 안내가 나오며 편집 메뉴의 붙여넣기를 사용할 수 있습니다. 외부 이미지는 파일 복사 후 Ctrl/Cmd+V 또는 이미지 불러오기를 사용하세요.

## 이전 편집기 데이터 정리

운영 담당자가 신규 코드와 DB 정리 migration을 배포한 뒤 사용합니다. 작업 불러오기 → 이전 편집기 테스트 데이터 정리 → 삭제 대상 확인에서 목록·건수·용량을 검토한 후 삭제합니다. 이전 출력 이미지까지 지우려면 별도 선택이 필요합니다. 현재 버전의 작업, 원본과 0번 대표 이미지는 정리 대상에서 제외됩니다. 상세한 운영 순서는 [변경 명세서](image-editor-feedback-rework-spec.md)를 참고하세요.
